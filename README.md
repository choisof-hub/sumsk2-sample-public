# SUMSK2 Sample / 出荷合計情報ツール（公開用サンプル）

## 概要

本リポジトリは、  
**Excelデータを読み込み、SQLiteへ取り込み・整形し、Tkinter GUIで集計結果を表示・Excel出力する業務支援ツール** の  
**公開用サンプル構成** です。

実際の業務システム画面や実データをそのまま公開するのではなく、  
**社外公開向けに安全性へ配慮したサンプル構成** として整理しています。

- Pythonで作成したデスクトップツール（Tkinter）
- Excelファイルを読み込み（pandas）
- SQLiteに一時格納・加工
- 届け先単位で集計表示
- 「標準」「注番」単位で集計表示
- Excel出力機能あり

---

## 公開方針（重要）

このリポジトリは **公開用サンプル** です。

以下の点に配慮しています。

- 実際の業務データは含みません
- 実在の取引先名・実在の品目情報は含みません
- 実際の業務画面をそのまま掲載せず、**説明用に再構成した画面イメージ（Excelモックアップ）** を使用しています
- 社外公開に適した範囲で、構成・考え方・実装例を示すことを目的としています

---

## このサンプルで伝えたいこと

このサンプルは、以下のような **実務寄りの対応力** を示すことを目的としています。

- 既存業務Excelの読み込み
- データ整形・項目名補正
- SQLiteを使った一時テーブル化
- GUIによる一覧表示
- 条件別の集計表示（標準 / 注番）
- Excelへの再出力
- 実画面を公開せずに、説明資料として安全に可視化する工夫

派手なWebアプリではありませんが、  
**現場業務で実際に役立つタイプのツール** を意識したサンプルです。

## 画面構成（公開用モックアップ）

公開用に、実画面を直接掲載せず **Excelで再構成した画面イメージ** を用意しています。

### 1. メイン画面
以下の操作を行う想定です。

- 出荷明細データ取込
- 売上データ取込
- 届け先選択画面を開く
- 対象日付・時間帯の指定

### 2. 届け先選択画面
指定した日付・時間帯のデータをもとに、届け先ごとの一覧を表示します。

**表示項目：**
- 届け先名称
- 枚数

**ここから実行できる処理：**
- 選択（標準）
- 選択（注番）
- 明細出力

### 3. 合計出荷情報（標準）
届け先単位で、**標準集計** を表示します。

**表示項目：**
- 品目コード
- 枚数
- 個数

この画面から **EXCEL出力** が可能です。

**出力ファイル例：**
- `届け先A_出荷合計数（標準）.xlsx`

### 4. 合計出荷情報（注番）
届け先単位で、**注番単位の集計** を表示します。

**表示項目：**
- 注番
- 品目コード
- 枚数
- 個数

この画面から **EXCEL出力** が可能です。

**出力ファイル例：**
- `届け先A_出荷合計数（注番）.xlsx`

### 5. 出荷明細（EXCEL出力）
届け先単位で、明細データをExcel出力します。

**出力項目：**
- GRP
- 品目コード
- 品名
- 個数
- 注文番号
- 棚番
- 売上№
- 行番号

**出力ファイル例：**
- `届け先A_出荷明細.xlsx`

## 処理概要

### 1. 出荷明細データ取込
- Excelファイルから出荷明細データを読み込み
- SQLiteへ取り込み
- 集計用の一時テーブルとして利用

### 2. 売上データ取込
- Excelファイルから売上データを読み込み
- 必要なデータをSQLiteへ取り込み
- 明細との突合に使用

### 3. 届け先選択
- 指定した日付・時間帯のデータを対象に
- 届け先ごとの一覧を表示

### 4. 合計出荷情報（標準）
- 届け先単位
- 品目コード単位で集計
- 表示 / Excel出力

### 5. 合計出荷情報（注番）
- 届け先単位
- 注番 + 品目コード単位で集計
- 表示 / Excel出力

### 6. 出荷明細出力
- 届け先単位
- 明細データをExcel出力
- 品目コードの切り替わりで `GRP` 列に記号を付与（公開用サンプル）
